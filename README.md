# Telegram Party Mode — iOS implementation reference

Работающий SwiftUI-прототип для передачи разработчикам Telegram iOS. Показывает создание группы жестом, сцену Party Mode, диско-шар, интерактивные аватары, стикеры и смену темы чата.

**Разработчикам: начните с [карты интеграции](docs/TELEGRAM_INTEGRATION.md).** Она связывает компоненты этого проекта с точками расширения Telegram iOS и отделяет готовые визуальные эффекты от работы с реальными данными.

For English-speaking developers: [implementation handoff](docs/HANDOFF_EN.md).

Это исходный материал для внедрения, а не готовый патч к Telegram. Демо использует собственные модели `Conversation`, локальные реплики и состояние в памяти. Сетевые операции, сохранение между запусками и межклиентская синхронизация не подключены. Приложение не связано с Telegram Messenger и не является официальным клиентом.

## Запуск

Требуются macOS, Xcode 27, Swift 6, SDK и симулятор iOS 27, Metal Toolchain. Внешних пакетных зависимостей нет.

```sh
git clone https://github.com/KirillMigel/telegram-party-mode-ios.git
cd telegram-party-mode-ios
open LiquidChats.xcodeproj
```

В Xcode выберите схему `LiquidChats` и iPhone Simulator, затем Run. Подпись для симулятора не нужна. Для физического iPhone задайте собственные Team и Bundle Identifier; в репозитории Team пустая, Bundle Identifier — `com.example.telegram-party-mode`.

```sh
./scripts/check.sh        # Все исполняемые проверки
./scripts/build.sh        # Сборка Release для iOS Simulator без подписи
./scripts/build.sh Debug  # Сборка Debug
python3 scripts/preflight.py
```

Если Xcode сообщает об отсутствии Metal Toolchain, установите компонент через настройки Xcode или `xcodebuild -downloadComponent MetalToolchain`.

## Как увидеть основной сценарий

1. Удерживайте строку Ewan, перетащите её на Alicia и отпустите. Можно добавить Thomas и Jessica к `New Group` тем же жестом. Для VoiceOver доступны действия `Combine with another person` и `Create`.
2. Нажмите Create. В чате появляются локальные реплики участников; плашка `Party mode` расположена над поднятым полем Message.
3. Нажмите Start. Кнопка превращается в диско-шар и перелетает к аватарам, появляются лучи на 360°, ripple и пульсирующие стикеры. Баблы плавно опускаются к полю ввода.
4. Нажмите шар: задайте название, затем выберите аватарку, затем тему. Для сохранения темы используйте синюю галочку. Это последовательность настройки демо; полноценное меню повторного редактирования нужно добавить в хосте.
5. Потяните аватар или стикер. При отпускании мимо сообщения элемент возвращается пружиной; стикер можно прикрепить к баблу.
6. Дважды нажмите на сообщение участника: из его аватара вылетают эмодзи.

При первом выборе аватарки PhotoKit запрашивает доступ к медиатеке. После выдачи разрешения собственная сетка открывается сразу. Поддерживаются ограниченный доступ, добавление разрешённых фото, отказ и загрузка из iCloud. Демо не отправляет выбранные фото на сервер.

## Для внедрения

В Telegram следует перенести визуальные компоненты и расчёты движения, подключив их к существующим владельцам данных, разрешений и жизненного цикла. Общий `ChatsPrototype` служит демонстрационным координатором; его не нужно встраивать как второй полноценный экран чата. Интеграция в приложение на UIKit/AsyncDisplayKit, сборка в Bazel, совместимость с поддерживаемыми версиями iOS и оптимизация остаются работой принимающей команды. Подробности: [TELEGRAM_INTEGRATION.md](docs/TELEGRAM_INTEGRATION.md).
